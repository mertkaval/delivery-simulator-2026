# Glass materials (PM_Glass*): build decisions

Builder: `tools/materials/procmat/glass.py` (key `glass`). Source: Ryan King Art, "Procedural Textured Frosted Glass
Materials (Blender Tutorial)", 2026, YouTube `SNKNqHd0AYI`, built in Blender 5.1.1 in the video. Specification:
`GRAPH_SPEC_a.md` (Circles, Voronoi, Cells) and `GRAPH_SPEC_b.md` (Wavy, Blobby, Frosted); extraction decisions a1-a10
(`DECISIONS_a.md`) and b1-b9 (`DECISIONS_b.md`). Project decisions D1-D11 (`tools/materials/DECISIONS.md`) are binding
and unchanged. These are to be merged into the library decisions log by the docs step.

Evidence classes: **A** seen in a frame, **B** narration only, **C** our inference / implementation, **D** unresolved.
Every node of the built groups carries its class and video times in the custom property `pm_note` (see `NODES.md`).

## Decisions

| # | decision | class | reason |
|---|---|---|---|
| G1 | Six materials, one group each: `PM_GlassCircles`, `PM_GlassVoronoi`, `PM_GlassCells`, `PM_GlassWavy`, `PM_GlassBlobby`, `PM_GlassFrosted`. The common glass base (Object coordinates -> Mapping -> textures; Glass BSDF Multiscatter GGX with Color / Roughness / IOR from the group) is one Python helper (`_Base`) but each group carries its own copy, as in the video (no shared sub-group). The video's group names are stored in `pm_video_group`. | C | the video builds six independent groups; a shared sub-group would change the graph the user sees and the road tool needs one self-contained group per material (D2) |
| G2 | The video's group output `Shader` is the contract's `BSDF`; `Albedo` = `Glass Color` (the tint). No `Metallic` / `Height` / `Alpha` outputs. | C | D2 contract names; the glass tint is the only "albedo" the material has |
| G3 | Voronoi and Noise use the core's `exact3d=True` twins: object mode (Use UV 0) evaluates exactly the video's 3D texture (same cells as the video for the same object coordinates); UV mode evaluates a 4D twin on the torus. The twins are mixed by `Use UV` (`<id>_mode` Mix nodes). | C | a 2D slice of 4D cells differs from 3D cells (API notes); the comparisons confirm the cell layout of the video in object mode (layout NCC peaks at zero shift for Cells / Voronoi / Blobby) |
| G4 | `Pattern Size` (metres per unit of the video's object space, default 1, in the closed Mapping panel) divides the Mapping Scale and multiplies every Bump Distance, so a larger pattern keeps the same relief shape. The video's `Scale` is kept unchanged as its first control. | C | D4: one size control in metres; the video's Scale socket stays as the user knows it |
| G5 | Mapping: the video's Mapping (Point, Location 0, Rotation 0 / Wavy `Rotation`, Scale) is fed by the contract coordinates `C.V` (object position in metres, or the torus point); the torus' 4th coordinate W is scaled by the same factor (`mapping_w`). | C | keeps the video's node while allowing UV mode; the torus arc length is metres, so densities per metre are the same in both modes |
| G6 | Wavy, UV mode: the Gabor Texture has no 4D variant (D5). The UV point is placed on the video's pane plane (u -> X, v -> Z, `pane_plane` nodes) and four 3D Gabor samples are cross-faded by `core.Coordinates.seamless` (smoothstep band 0.15 of the tile), with the variance-preserving gain of G17. Object mode is the single video Gabor. | C | D5 adaptation; the bake proves the tile repeats (periodicity corr 0.99999) |
| G7 | Gabor Orientation 3D = (0.797, 0.604, 0.0) from the Lambert fit of the direction ball (spec b D1); Gabor Scale 12 is a constant inside the group (not exposed), as in the video. | C / A | the numbers are never shown; the scale is narrated as deliberately not exposed (B 25:00) |
| G8 | Colour-ramp stops stored scene-linear from the picker's perceptual value with the sRGB EOTF: Cells #A8A8A8 (V 0.659) -> 0.3916; Blobby V 0.700 -> 0.448; Frosted V 0.342 / 0.719 -> 0.0958 / 0.4755. | C | the picker shows perceptual values, ramps store linear (a4, b3) |
| G9 | RGB Curves: only the combined (C) curve is edited, points (0,0), the read points, (1,1), auto handles, Factor 1; Circles (0.314, 0.2464), (0.5804, 0.6535); Voronoi 1 (0.6758, 0.2928); Voronoi 2 (0.6331, 0.3000). | A (handle type C) | the curve widget shows auto (smooth) handles; the exact Bezier handle math is Blender's |
| G10 | Bump Filter Width = 0.1 (Blender 4.4+ socket, the 5.1.1 default the video shows). Voronoi bump 2 Distance = 0.00008 (typed), Wavy 0.0007 (typed). | A | a7; the field rounds the display |
| G11 | Interface rows are the video's names, order, defaults and limits; limits never displayed take the twin socket's / Blender's limits (Voronoi Detail 0..15, Randomness 0..1, Frosted Detail 2 Factor 0..1). Descriptions are ours (the video's were truncated or empty). | A / C | a5, b4, spec D5 |
| G12 | Glass BSDF Thin Film inputs left at the defaults (thickness 0, IOR 1.33); Glass Color white. | C | the Thin Film panel is never opened (spec a / b D7) |
| G13 | Material settings: displacement method Bump (no displacement output in the video); EEVEE `surface_render_method = DITHERED` with `use_raytrace_refraction = True`; viewport colour (0.80, 0.85, 0.87) with alpha 0.3-0.6 and the mean BSDF roughness, which the road tool's flat glTF fallback reads. | C | the video renders in Cycles only; Dithered + raytraced refraction is the EEVEE (5.x) mode that refracts what is behind an object, Blended would not refract |
| G14 | Validation scene = the video scene rebuilt from the spec: six 0.8 m panes (2 m plane, S 0.4, R X 90, scale applied: object coordinates = the video's), 3 x 2 grid at 0.874 / 0.856 m pitch measured on the 33:23 frame, red Suzannes (#F40D00) behind, camera 50 mm at 4.435 m, Cycles, Filmic + Very High Contrast, film transparent, bundled HDRI at strength 0.5. Suzanne scale / positions are fitted to frames (class D in the video). | C | D6 and spec scene notes; the camera distance follows from the frame width at the panes |
| G15 | Lighting search before any material change: city 0-270, courtyard 0-270, interior 0-270, studio, forest, sunset; reference runs use interior 90 (r2, closest mean brightness) and sunset 270 (r3 / r4, bright neutral backdrop like the video's walkway). | C | D6: the video HDRI `old_apartments_walkway_1k` is not available; lighting changes the texture contrast seen through the glass by up to 1.8x (VALIDATION section 3) |
| G16 | No material value was changed after the comparisons: every remaining difference is explained by lighting, scene placement or render settings (VALIDATION section 4). The audit fixes G17 / G18 change only class C adaptations (UV-mode blend, Wavy orientation off the video's pane); the video's pane renders the same field as before. | - | class A values are not tuned to match a different environment |
| G17 | Wavy, UV mode (audit GL-2): the four-sample cross-fade is variance-preserving: value = 0.5 + (cross-faded value - 0.5) / sqrt(((1-wu)^2 + wu^2)((1-wv)^2 + wv^2)) (`seam_gain`, `gabor_relief`; wu / wv = the cross-fade weights, 0.5 = the measured Gabor Value mean). A plain cross-fade of two independent samples keeps only sqrt(0.5) of the deviation at the band centre: the relief dropped by about a third there (measured -33..-35 % column std of the baked normal map). Now -1 % (1 m bake and field probe). Object mode: weights 0, gain 1, unchanged. | C | keeps the streak amplitude constant across the tile; implemented in the material (the core's `seamless` documents its contrast drop and stays unchanged) |
| G18 | Wavy, object mode (audit GL-1): the Gabor Orientation 3D is applied **relative to the surface**. From the object-space shading normal N (side fixed by N . (0.1, -1, 0.05) > 0, so both faces of a pane give the same field) and the horizontal in-plane tangent H = normalize(Z x N + 0.001 X), the orientation is 0.797 H - 0.604 N. On the video's X-Z pane (N = -Y) this is exactly (0.797, 0.604, 0): the field is the video's (probe corr 0.9996 to the previous build, 8-bit). Every other pane sees the same projection: vertical streaks, period 1 / (12 x 5 x 0.797) = 2.1 cm (measured X-Z 2.00 cm, Y-Z 2.17 cm, X-Y 1.99 cm with streaks along Y; before: Y-Z 2.78 cm (+39 %), X-Y diagonal at 142 deg, 1.8 cm). UV mode keeps the constant vector (UV lies on the video's pane plane). `Rotation` still rotates the Mapping in object axes: to tilt the streaks, rotate about the pane's normal axis (Y for an X-Z pane, X for a Y-Z pane). Limit: on a curved glass whose normal crosses the plane N . (0.1, -1, 0.05) = 0 the side choice flips (a seam). | C | the road tool's bus shelter mesh has back glass in X-Z and side glass in Y-Z in one mesh (`tools/roads/mrs/furniture.py`), and Wavy is recommended for shelter side panels |
| G19 | Blobby relief (audit GL-3) stays as built: the controlled test (VALIDATION section 8) shows (1) the video's 27:42 graph typed literally as a plain material renders pixel-identically to `PM_GlassBlobby` (mad 0.0), (2) the Bump Distance was typed "0.004" (frame 27:37.9, cursor after the 4), (3) the Blobby / Voronoi contrast ratio depends on the backdrop: 0.46 (HDRI only), 0.34 (checker card), 0.45 (bright spot), 0.37-0.38 in the video scene, vs 0.52 in the video. No class A value is changed; the deviation is kept open as scene / lighting (D6, Suzanne and backdrop class D) with a possible 5.1.1 -> 5.2.3 renderer difference not testable here. | A / C | changing the bump would contradict the frames; the remaining cause is outside the material graph |

## Version adaptation: Blender 5.1.1 (video) -> 5.2.3 (build)

| tutorial node / behaviour | Blender 5.2 equivalent | adaptation | expected effect |

| Voronoi Texture 3D (Smooth F1, Distance to Edge, fractal Detail / Roughness / Lacunarity, Normalize) | same node, same sockets | none in object mode; UV mode adds a 4D twin (`voronoi_dimensions = '4D'`) on the torus | object mode identical; UV mode: same density and statistics, different cell layout, seamless |
| Noise Texture 3D fBM, Normalize | same node | as above (4D twin in UV mode) | identical / seamless |
| Gabor Texture 3D (added in 4.3) | same node, 2D / 3D only | UV mode: four-sample variance-preserving cross-fade (G6, G17); object mode: orientation relative to the surface (G18) | object mode identical on the video's X-Z pane, same streaks (vertical, 2.1 cm) on any other pane; UV mode: streak amplitude within 1 % across the 15 % blend band (was -33 % at its centre before G17) |
| Bump (Invert, Distance, Filter Width 0.1) | same node | none | identical |
| RGB Curves, Color Ramp (RGB, Linear), Hue/Saturation/Value, Map Range (Float, Linear, Clamp) | same nodes | ramp colours converted to linear (G8) | identical within the picker's 3-decimal readout |
| Glass BSDF Multiscatter GGX (+ Thin Film panel, 4.2+) | same node | defaults (G12) | identical |
| Mapping (Point) | same node | Vector from the contract coordinates (G5) | identical in object mode |
| Group interface panels / Factor subtype | `NodeTreeInterface` sockets with `subtype`, panel "Mapping" for the library inputs | contract inputs added in a closed panel | the video's controls stay at the top in the video's order |
| Cycles viewport (Sample n/100, no denoise) | Cycles final render | VALIDATION r4 uses 100 samples and no denoising to match the viewport frames | the denoiser hides the Frosted mottle (r2 / r3 halve its contrast) |
| Filmic view transform, Very High Contrast look | still available in 5.2 (`Filmic`, look `Very High Contrast`) | set explicitly in the validation scenes; the library rig defaults to AgX | only the validation renders |

## Scale conversion (metres)

The video's panes are 2 m planes scaled 0.4 with the scale applied (A 3:26-3:34), so the material reads Object
coordinates in metres on an object with scale 1. The video's texture scales are therefore **per metre** as they stand
and are kept: Circles 50 dimples/m (2 cm), Voronoi 30/m (3.3 cm) twice, Cells 30/m + roughness noise 20/m, Wavy Gabor
12/m x frequency 5 (streak period about 2.1 cm across any pane, G18), Blobby 10/m (10 cm blobs) + noise 20/m, Frosted noise
20/m. Bump distances are metres: 2 mm, 4 mm + 0.08 mm, 3 mm, 0.7 mm, 4 mm. `Pattern Size` (G4) rescales all of them
together. In UV mode `Tile Size` metres span UV 0..1 and the same densities apply (torus arc length = metres).
A road tool glass object must have applied scale (or UVs in metres with Use UV 1) for these sizes to hold.
